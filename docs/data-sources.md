## Genuine adapter
GET `https://api.worldbank.org/v2/country/IRL;FIN;CAN/indicator/EG.ELC.RNEW.ZS?format=json&per_page=300`.
Response `[pagination, observations]`; verify all three iso3 codes, indicator id, finite percentage 0–100, four-digit year, latest non-null row by year. Reject the whole import if any country is missing/malformed. Response observed 2026-10-05: 198 rows, page 1 of 1, lastupdated 2026-07-13. Latest non-null reporting year is **2021** for all countries; IRL 37.1541775946047%, FIN 52.9302986606029%, CAN 67.0163805768966%. Exact verified results in reports/refresh/verified-api-response.json; full public fixture in tests/fixtures/worldbank.json.
Unit normalized from indicator definition to percent (response unit string is empty). Underlying IEA attribution, World Bank data CC BY 4.0 terms subject to indicator metadata. Annual output basis, no facility tariff, complete source mix, 24/7 matching or hourly carbon claim. Historical dataset is useful for screening, inadequate as current-site evidence.

Refresh: editor/admin only, approved adapter, 15s timeout, immutable metric rows and superseding ID on change; unchanged observations preserve original retrieval time and create separate successful-check run. Failures log rejected outcome and preserve last-valid values/timestamps. Public metric history; protected refresh outcomes. Adapter endpoint/parameters cannot come from browser arbitrary URLs.

Freshness: historical annual output is marked historical by reporting year, not automatically invalid. Recheck API at 30 days; policy review target 90 days or immediately on known change; cost/tariff assumptions reviewed before approval and never marked verified. Retrieval date is check provenance, not reporting vintage. Missing carbon/count/water/latency/permit/quote fields remain explicit unknown.
